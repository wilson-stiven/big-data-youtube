# Tarea 4 – Almacenamiento y Consultas de Datos en Big Data  
# YouTube Analytics con MongoDB

Este repositorio contiene el desarrollo de la Tarea 4 del curso **Big Data**, utilizando el dataset *YouTube Analytics Data* de Kaggle y la base de datos NoSQL **MongoDB**.  
Incluye el diseño de la base de datos, consultas CRUD, consultas con `$expr`, agregaciones avanzadas y scripts de importación.
