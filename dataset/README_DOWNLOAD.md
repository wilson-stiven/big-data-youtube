## 📥 Cómo descargar el dataset

1. Ingrese al enlace del dataset en Kaggle.
2. Haga clic en **Download**.
3. Descomprima el archivo `.zip`.
4. Busque el archivo CSV principal (por ejemplo: `youtube-analytics-data.csv`).
5. Coloque el archivo dentro de esta carpeta `dataset/`.
